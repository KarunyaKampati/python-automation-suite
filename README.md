# 🚀 Python Automation Suite with GUI
Python Automation Suite with GUI built using Tkinter.  Includes file organization, web scraping, and system monitoring features to automate daily tasks.


## 📌 Project Description
This project is a Python-based Automation Suite with a graphical user interface (GUI) built using Tkinter.

It automates:
- File Organization
- Web Scraping
- System Monitoring

## 🛠 Technologies Used
- Python
- Tkinter
- BeautifulSoup
- psutil

## ▶️ How to Run
1. Install dependencies:
   pip install requests beautifulsoup4 psutil

2. Run:
   python gui.py

## 🎯 Features
- Auto file sorting
- Website data extraction
- System performance tracking
- GUI interface
